# E-Commerce-Customer-Churn-RFM-Segmentation-SQL-Only-
SQL-only cohort retention and RFM segmentation on a Brazilian e-commerce dataset. Window functions, nested CTEs, no pandas. Key finding: month-1 retention under 1% isn't a churn crisis — it's structurally normal for a marketplace. Champions + At Risk = 31% of customers, 55% of revenue.
